Gauge Selection — SMACNA Table 6-1 / 6-2 (Rectangular, 2" w.g. static)
Gauge is selected by the LONGER side = MAX(Width, Depth), against whichever table (6-1 or 6-2) matches Tab 1's Standard Duct Section Length setting. Both tables stop at 96" (2438mm) — see Tab 2's out-of-range warning for anything larger.
Duct Support — SMACNA Table 6-7, Section C (Horizontal Trapeze-Type)
Gauge Selection — SMACNA Table 6-8 (Round, Pressure <2" w.g. static)
Gauge is selected by Diameter. Only the Round, <2" w.g. (Low Pressure) column was transcribed — Table 6-8 also gives separate Flat-Oval and >2"–<10" w.g. Spiral/Longitudinal-Seam/Welded-Fittings values this app doesn't model (no seam-type or flat-oval input yet). Table stops at 84" (2134mm) — see Tab 2's out-of-range warning for anything larger.
Material Thickness Equivalency — SMACNA Table 6-3 (Rectangular Aluminum Duct, Alloy 3003-H14)
Converts the steel-equivalent gauge Tab 2 already assigns into an aluminum thickness — used when Tab 1's Duct Material is set to Aluminum. Table 6-3's own weight row says "Consult Appendix-5 for Weights," which wasn't part of the supplied source pages, so weight here is computed from thickness × a general aluminum density constant (2700 kg/m³) instead of a SMACNA-tabulated figure. Not yet implemented: Table 6-4 (Dimension Adjustments — keyed by a different "Rigidity Class" A–L lettering not confirmed to align with Table 6-1/6-2's Reinf. Code Grade C–I) and Table 6-5 (Reinforcement angle/bar aluminum equivalents — this app hasn't transcribed the underlying steel angle/bar sizes for the reinforcement codes either).
Duct Thickness — SMACNA Table 6-9 (Single-Dwelling Unit, Heating or Cooling)
Residential-only reference — a distinct, lighter-duty use case from the general commercial brackets above. Not wired into any calculation in this app; see the note below the table.
Minimum Conveying Velocities — SMACNA Table 5-1
Airflow/exhaust duct sizing reference (dust/fume conveying velocity) — a different engineering discipline from material takeoff. This app has no airflow/CFM input, so this table is reference only and does not feed any calculation here.

Construction terminology (general reference, not a numeric table)
Seams — the longitudinal joint closing a duct section into a tube shape (e.g. Pittsburgh lock: a folded mechanical interlock along the seam).
Joints — the transverse connection between duct sections (e.g. S-slip and drive-slip for low pressure; standing seam for heavier/higher-pressure duct).
Reinforcement — stiffening added to large flat duct faces to control panel deflection (e.g. cross-breaking, angle-iron bracing) — required more as duct size/pressure class increases.
Connectors — hardware joining duct sections or duct-to-equipment (slip connectors, companion angles/flanges).
Flanges — bolted duct-to-duct or duct-to-equipment connections, typically at equipment tie-ins or where sections must be demountable.
This is general descriptive orientation, not a substitute for the applicable SMACNA construction table — verify exact spacing/reinforcement requirements against your SMACNA 3rd Ed. manual.
